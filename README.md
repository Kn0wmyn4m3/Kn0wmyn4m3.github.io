# Kn0wmyn4m3.github.io

Personal developer portfolio hosted on GitHub Pages: **[https://kn0wmyn4m3.github.io](https://kn0wmyn4m3.github.io)**

## Stack
- Plain semantic HTML5, CSS3 (light/dark theme with `prefers-color-scheme`), and vanilla ES Modules
- Zero build step, zero external CDN dependencies, zero trackers

## Local Preview
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000`.
